# Soil electrical conductivity meter

The soil electrical conductivity meter is a device designed to see how easily soil conducts electricity. It was made using an Arduino Uno R3 and transmits the data via Bluetooth to a connected cell phone. To use it, simply press the button on the board with the cell phone connected and the nails in the soil, which will then send the data to the cell phone.
